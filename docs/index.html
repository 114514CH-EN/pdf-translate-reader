译文长得和原文一样

The translation looks like the page

不是把文字抽出来再排一遍：标题、编号缩进、表格单元格、颜色和字号都按原 PDF 的位置放回去。公式直接从原页截取，下标上标一个不乱。

The text is not pulled out and re-flowed. Headings, numbered indents, table cells, colours and sizes go back where they were on the original page, and formulas are cropped straight from it, so subscripts and superscripts stay intact.

  • 逐句对照视图，每一句都能单独改
  • A sentence-by-sentence view where every sentence can be edited
  • 术语库：全局 + 每篇文档，可自动抽取
  • Glossary, global and per document, extracted automatically
  • 导出纯译文 PDF、左右对照 PDF、Markdown
  • Export a translated PDF, a side-by-side PDF or Markdown
  • 翻译前先估算 token、费用和时间
  • Tokens, cost and time are estimated before you translate

改原文、改公式，或者从一张白纸开始

Edit the page, the formulas, or start from a blank sheet

点「编辑译文」，左边的原文和右边的译文都变成可以直接改的页面。改过的内容按原位置写回 PDF，导出就是成品。

In edit mode both the original and the translation become pages you can change in place. Your changes are written back into the PDF where they stand, so the export is the finished document.

  • 改字、调字号颜色、移动、改大小，表格逐格改，整篇查找替换
  • Rewrite text, change size and colour, move and resize, edit table cells, find and replace
  • 公式用 LaTeX 改写，边写边看效果
  • Rewrite formulas in LaTeX with a live preview
  • 文本框、图片、直线、箭头、矩形、椭圆，点哪放哪
  • Text boxes, pictures, lines, arrows, rectangles and ellipses, placed where you click
  • 加页、删页，拖动小图调整页序
  • Add and delete pages, and drag thumbnails to reorder them

回来时，停在你离开的那一页

Back where you left off

首页最前面是上次在读的文档，翻开就是你停下的那一页；下面是全部文档，可以搜索、排序，鼠标停一下就能预览。读的时候随时点左上角的「首页」，回去也不会丢掉位置。

The home page puts the document you were reading in front, open at the page where you stopped, with the whole library below to search, sort and preview. The Home tab is always one click away and the open document keeps its place.

  • 专注阅读（按 F）：收起所有栏，只留两页
  • Focus reading (press F) hides every bar and leaves the two pages
  • 9 种界面风格，电子墨水主题下页面可选灰度或原色
  • 9 themes; in the e-ink theme pages can be greyscale or in colour
  • 中文 / English 界面一键切换
  • Switch the interface between Chinese and English

桌宠小页，陪你读

小页, a reading buddy

同一个程序的第二个界面：阅读助手变成趴在窗口下沿的一张小纸片。点它弹出对话，选中文字它就跑出来；在一页停留一会儿，它会问要不要讲讲这页的公式或表格。

A second interface for the same app: the reading assistant becomes a small sheet of paper sitting on the bottom of the window. Click it to chat, and it comes out when you select text. Stay on a page for a moment and it offers to explain the formulas or tables there.

  • 读书挣零食，喂它涨亲密度，升级解锁头饰
  • Reading earns treats; feeding it raises your bond and unlocks charms
  • 扔球给它追、猜拳、每日一签，还会用你文档里的术语出题考你
  • Throw it a ball, play rock–paper–scissors, draw a daily fortune, and let it quiz you on your document's own terms
  • 专注计时、今日页数、每日目标，读够了它会庆祝
  • Focus timer, pages read today and a daily goal it celebrates with you
  • 换成你自己的图片或 GIF，自动去背景
  • Give it your own picture or GIF; backgrounds are removed for you

你的文档留在你的电脑上

Your documents stay on your computer

程序在本机运行，文档、译文、笔记都存在项目的 data/ 文件夹里。只有在翻译或提问时，相关文字才会发给你自己配置的大模型 API；API Key 加密保存。想完全离线，可以接本地的 Ollama 或 LM Studio。

The app runs locally, and documents, translations and notes are stored in the project's data/ folder. Text is sent only to the LLM API you configure, and only when you translate or ask a question; API keys are stored encrypted. To stay fully offline, point it at a local Ollama or LM Studio.

常见问题

FAQ

需要装 Node.js 吗？Do I need Node.js?

不需要。Windows 版（PDFTranslate.exe）什么都不用装；从源码运行只要 Python 3.10 或更新的版本。只有自己改前端代码时才需要 Node.js。

No. The Windows app (PDFTranslate.exe) needs nothing installed; running from source needs only Python 3.10 or newer. Node.js is only needed if you change the frontend code.

翻译一篇论文要多少钱？How much does translating a paper cost?

取决于你用的模型。点「翻译全文」前会先估算 token 数和费用；设置里的「用量」页按用途和文档记账，DeepSeek 还会按缓存命中和峰谷时段计价。

It depends on the model. Tokens and cost are estimated before you start, and the Usage page in Settings keeps a record by purpose and by document, including DeepSeek's cache-hit and peak/off-peak pricing.

界面有英文吗？Is the interface available in English?

有。点标签栏右侧的 EN 切换，再点「中文」切回。桌宠说的话目前还是中文。

Yes. Click EN at the right of the tab strip (and 中文 to switch back). The desktop pet still speaks Chinese.

支持 macOS 或 Linux 吗？Does it work on macOS or Linux?

启动脚本是为 Windows 写的。程序本身是 Python + 浏览器，在 macOS / Linux 上可以按 README 的「开发」一节手动启动，但没有专门测试过。

The launch scripts are written for Windows. The app itself is Python plus a browser, so it can be started by hand on macOS or Linux as described under Development in the README, but those systems are not tested.
